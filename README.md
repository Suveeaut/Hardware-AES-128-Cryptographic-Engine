# Hardware AES-128 Cryptographic Engine

Two 128-bit AES encryption microarchitectures in SystemVerilog—an area/power-optimized **iterative** design (`aes_128_iter`) and a high-throughput **10-stage pipelined** design (`aes_128_pipe`)—verified against NIST FIPS-197 vectors and implemented on a **Virtex-7** FPGA at **100 MHz**.
